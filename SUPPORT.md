# Support

- **Questions and usage help:** start a [GitHub Discussion](https://github.com/pierkulakov/deckmate/discussions).
- **Bugs:** use the [bug report template](https://github.com/pierkulakov/deckmate/issues/new?template=bug_report.yml) in GitHub Issues and include the requested reproduction details.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md); do not open a public issue.

See [README.md](README.md) for installation and use, and [CONTRIBUTING.md](CONTRIBUTING.md) for development setup, tests and pull requests.
