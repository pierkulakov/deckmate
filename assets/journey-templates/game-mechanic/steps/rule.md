Write the rule without engine terminology: what the player does, what happens in response, and when the rule does not apply. Done when the rule can be explained in a minute without pictures.

- [ ] Write the rule in three to five sentences
- [ ] Include examples of use
- [ ] Describe the limits: when the rule does not apply
