## Deckmate board

This project's board lives in Deckmate: never read `cards/` wholesale or write card files by hand — work through the `deckmate` MCP server (`next` → work → `report` with state review; `create_cards` for new work), or without MCP through `deckmate project --help`, which runs the same route. Never accept your own work; when blocked, `ask` instead of guessing. Longer routes — planning, review, Journey steps, design documents, playtests, team setup — live in the `/deckmate` skill.

Bring a question ref (c-…#N) into chat to discuss and answer it; next returns pending decisions first: edit the target, then apply_decision.
